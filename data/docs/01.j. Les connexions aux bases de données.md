# Les connexions aux bases de données

La classe `SAND\Classe\Bdd` ouvre des connexions PDO **nommées**. Chaque nom correspond à un jeu de constantes déclarées dans `application/config/bdd-parameters.php` (copie locale de `bdd-parameters.php.skel`, à ne jamais versionner).

## Déclarer une connexion

Une connexion se déclare en deux temps : son nom dans la liste blanche, puis ses constantes.

### Format du nom et liste blanche

+ Un nom de connexion respecte le format `^[a-z][a-z0-9_]{0,31}$` : une lettre minuscule, puis au plus 31 minuscules, chiffres ou `_`. Tout autre nom (majuscules, tiret, saut de ligne, chemin…) lève une `InvalidArgumentException`, dont le message ne recopie pas la valeur reçue.
+ Le nom doit figurer dans la constante `BDD_CONNEXIONS_AUTORISEES` (tableau de noms). Sa valeur par défaut, définie dans `application/config/constantes-par-defaut.php`, est `['default', 'bdd1', 'bdd2']`. Pour ajouter une connexion, la redéfinir dans `app-parameters.php` (ou `bdd-parameters.php`), qui sont chargés avant :

```php
define('BDD_CONNEXIONS_AUTORISEES', ['default', 'bdd1', 'bdd2', 'annuaire']);
```

+ Un nom hors de la liste est refusé (`InvalidArgumentException`), même si ses constantes `DSN_BDD_<NOM>` existent. La liste blanche empêche un nom venu d'un `.model` modifié, ou d'un appelant qui passerait une valeur du visiteur, d'atteindre une autre constante `DSN_*`.

### Constantes de la connexion

Pour une connexion nommée `<nom>`, déclarer trois constantes, le suffixe étant le nom en majuscules :

```php
define('DSN_BDD_ANNUAIRE', "mysql:host=localhost;dbname=annuaire;charset=utf8mb4");
define('USER_BDD_ANNUAIRE', "utilisateur");
define('PASS_BDD_ANNUAIRE', "mot_de_passe");
```

+ `DSN_BDD_<NOM>` est obligatoire. `USER_BDD_<NOM>` et `PASS_BDD_<NOM>` sont facultatives (chaîne vide par défaut, utile pour SQLite).
+ **Forme historique :** pour un nom `bdd<chiffres>` seulement (`bdd1`, `bdd2`…), si `DSN_BDD_<NOM>` n'existe pas, `Bdd` lit `DSN_<NOM>`, `USER_<NOM>` et `PASS_<NOM>` : les connexions `bdd1` et `bdd2` du modèle (`DSN_BDD1`, `DSN_BDD2`) continuent de fonctionner. Si les deux formes existent, `DSN_BDD_<NOM>` l'emporte. Pour tout autre nom, seule la forme `DSN_BDD_<NOM>` est lue.
+ La connexion `default` lit `DSN_BDD_DEFAULT`, `USER_BDD_DEFAULT` et `PASS_BDD_DEFAULT`.
+ Un nom autorisé sans constante lève une `RuntimeException` qui indique les constantes à définir (le message ne contient ni DSN ni mot de passe).
+ Si l'ouverture échoue (serveur injoignable, identifiants refusés…), `Bdd` journalise dans `app.error.log` le nom de la connexion et le SQLSTATE seulement, puis lève une `RuntimeException` générique (« Connexion BDD « <nom> » impossible »), **sans** l'exception PDO d'origine : sa trace porterait le DSN, l'utilisateur et le mot de passe.

## Utiliser une connexion

```php
$bdd = new \SAND\Classe\Bdd();            // connexion 'default'
$bdd = new \SAND\Classe\Bdd('bdd1');      // forme historique DSN_BDD1
$bdd = new \SAND\Classe\Bdd('annuaire');  // DSN_BDD_ANNUAIRE

$pdo = \SAND\Classe\Bdd::connexion('annuaire');       // l'objet PDO lui-même
[$dsn, $user, $pass] = \SAND\Classe\Bdd::identifiants('annuaire'); // résolution seule, sans connexion
```

Une seule connexion PDO est ouverte par nom pendant la requête : deux `new Bdd('annuaire')` partagent le même objet PDO (`$bdd->bdd`). Les connexions sont configurées en `PDO::ERRMODE_WARNING` et `PDO::FETCH_ASSOC`.

**Conséquences du partage :**

+ **Transaction commune :** une transaction ouverte par une instance (`$bdd->bdd->beginTransaction()`) vaut pour toutes les instances du même nom. Un `commit()` ou un `rollBack()` fait ailleurs dans la requête, par une autre classe, la termine pour tout le monde.
+ **Pas de transaction imbriquée :** un second `beginTransaction()` sur le même nom, alors qu'une transaction est en cours, lève une `PDOException`. Tester `$bdd->bdd->inTransaction()` avant d'en ouvrir une, ou centraliser la transaction chez l'appelant.
+ **`lastInsertId` partagé :** `getLastInsertId()` renvoie l'identifiant du dernier `INSERT` fait sur la connexion, quelle que soit l'instance qui l'a fait. Le lire juste après son propre `INSERT`.
+ Les attributs changés sur `$bdd->bdd` (mode d'erreur, mode de lecture…) valent aussi pour toutes les instances du même nom.

## Déclarer la connexion d'une page : clé `bdd` du `.model`

Une page peut déclarer sa connexion dans son fichier `.model` :

```
name : annuaire
page_title : Annuaire
bdd : annuaire
```

Dans le contrôleur de la page, la définition de la page est disponible dans `$page_params` :

```php
$bdd = \SAND\Classe\Bdd::pourPage($page_params); // connexion 'annuaire', ou 'default' sans clé bdd
```

`Bdd::pourPage()` prend la clé `bdd` (espaces retirés). Sans clé `bdd`, ou avec une valeur vide, la connexion est `default`. Une valeur qui n'est pas un nom valide (un tableau `{…}`, un nom mal formé) lève une `InvalidArgumentException`, de même qu'un nom absent de `BDD_CONNEXIONS_AUTORISEES`. `Bdd::nomPourPage()` renvoie le nom retenu sans ouvrir de connexion.

> **Règle :** `Bdd::pourPage()` ne s'utilise **qu'avec une définition de page issue d'un `.model`**, jamais avec des paramètres d'URL (`$_GET`, `$page_params['all_params']`, paramètres d'une route). Le choix de la base doit venir de la configuration de l'application, pas du visiteur.

## Requêtes et erreurs

`faireBindRequete($sql, $params)` prépare, lie et exécute la requête. Elle renvoie le `PDOStatement`, ou **`0`** en cas d'échec (préparation, exécution ou `PDOException`). L'échec est journalisé dans `application/logs/app.error.log` sur une ligne : nom de la connexion, SQLSTATE, code du pilote et message du pilote, ramené à une ligne (caractères de contrôle remplacés par des espaces) et tronqué à 120 caractères. Le journal ne contient jamais le DSN, l'utilisateur ni le mot de passe.

```php
$req = $bdd->faireBindRequete($sql, [['categorie', $categorie, \PDO::PARAM_INT]]);
if ($req === 0) {
    // l'erreur est dans app.error.log : ne pas appeler exploiterResultat()
    $lignes = [];
} else {
    $lignes = $bdd->exploiterResultat($req);   // fetchAll()
    $nombre = $bdd->exploiterNbResultat($req); // rowCount() : lignes touchées par un INSERT, UPDATE ou DELETE
}
```
